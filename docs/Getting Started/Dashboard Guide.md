# Dashboard Guide
## Navbar
It shows your username, Email, and profile photo.

## Left half
1. It indicates the connection with Hackatime, and shows YSWS eligibility

2. It shows recent mixes(a mix is a project you created). To view all the projects you have created, click on "VIEW ALL MIXES" button on the bottom right of the section.

## Quick actions tab
## Projects
This button leads to a page where you can view all your projects and create projects too.

## Creating a project
1. Click on "PROJECTS" button.
2. Click on "ADD MIX"
3. Give a name to your project(anything you wish).
4. Project description: write down a short description of your project, maybe list it's features if you want.
5. Attach the link of the project's GitHub repository.
6. Attach the link of the working demo of the project.
7. Upload a cover screenshot of it.
8. Select the project type (Hardware, Software...)
9. Choose 1 theme out of the 3.
10. Choose the project from your hackatime.

## Shop
This is the event's shop where you can spend your hard earned potion mix on.
